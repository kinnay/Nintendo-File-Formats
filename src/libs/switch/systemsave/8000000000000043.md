## private
The SD card identifier must be equal to the content of the `/Nintendo/Contents/private` file. Otherwise, the data on the SD card cannot be decrypted.

| Offset | Size | Description |
| --- | --- | --- |
| 0x0 | 16 | SD card identifier (random) |
| 0x10 | 16 | SD card encryption seed |
| 0x20 | 0x1E0 | Unknown |
